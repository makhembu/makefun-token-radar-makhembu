Autonomous Token Launch Radar and Liquidity Valuation Model. Evaluates DeFi and token launch protocols across multiple categories with TVL momentum tracking, protocol risk evaluation, and step-by-step strategy recommendations.

## Features

- **Category-Specific Multipliers:** Differentiated metrics for DEXes, Lending pools, Yield aggregators, and RWA protocols.
- **TVL Momentum Factor:** 7-day rolling TVL momentum curves to prioritize high-velocity liquidity.
- **Protocol Risk Scoring:** Multi-factor safety analysis balancing yield vs counterparty risks.
- **Terminal UI Dashboard:** Clean, interactive terminal interface with live filter pills, detail drawers, and sorting.

## Run it

```sh
npm install
npm run build
npm start
```
